# 🧹 Excel VBA Data Cleaning Project

## Overview
This mini project demonstrates how messy raw data can be transformed into a clean, ready‑to‑use dataset using **Excel VBA automation**.  
The VBA script was generated with the help of ChatGPT, customized to handle specific column issues and inconsistencies in the dataset.

## Features
- Automated removal of unwanted characters, space, random distribution of data, mixed cases.
- Standardized column formatting for consistency  
- One‑click execution inside the VBA editor (`Alt + F11`)  
- Produces a final dataset ready for analysis or reporting

## Workflow
1. Identified messy data structure and column issues  
2. Defined cleaning requirements clearly  
3. Generated VBA code using ChatGPT  
4. Implemented code in Excel VBA editor  
5. Executed script → messy data cleaned instantly
---



## How to Use
1. Open Excel → Press `Alt + F11` to access VBA editor  
2. Paste the provided VBA script into a new module  
3. Run the macro → Data gets cleaned automatically
